# Contributing

Clone `https://github.com/apoorvdarshan/apoorvdarshan.git` and create a branch.
Use GitHub Issues for bugs/feature requests, and pull requests for changes.
English reports are welcome. Include reproduction steps and the affected commit.
Search existing issues before opening a duplicate; avoid personal data/secrets.
Security reports follow [SECURITY.md](SECURITY.md), not public issues.

Keep changes focused and follow the surrounding style. Add regression tests for
bug fixes and automated tests for major functionality. Run the commands documented
in [BUILD.md](BUILD.md), and update interface documentation and CHANGELOG.md when
behavior changes. CI runs on pushes and pull requests. The maintainer can merge
with zero other-person approvals after checking applicable automated results.

Software license and third-party notices must be preserved. The current main
branch is the maintained development version; commit hashes identify continuous
updates, with tagged releases for reusable template versions. Releases require
human-readable notes and static/dynamic checks. Do not upload secrets or private
resume/report files. No App Store or Play Store release is part of this process.
